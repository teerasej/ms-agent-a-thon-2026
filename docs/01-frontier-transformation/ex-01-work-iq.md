# EX-01: ค้นหาสิ่งสำคัญด้วย Work IQ

คุณกำลังจะเข้าประชุมอัปเดตโครงการ แต่มีเวลาอ่านข้อมูลเพียงไม่กี่นาที ให้ Copilot ช่วยค้นหาความคืบหน้า ความเสี่ยง และสิ่งที่ต้องทำต่อจากไฟล์ที่ได้รับ

> **สิทธิ์ใช้งาน:** การ Upload ไฟล์

## Scenario: เตรียมตัวก่อนประชุม

### Practice 1: สรุปข้อมูลจากไฟล์ที่กำหนด

ใน Practice นี้ พวกเราจะใช้ Copilot เพื่อค้นหาข้อมูลสำคัญสามรายการและตรวจสอบว่าแต่ละรายการมาจากไฟล์ใด

1. กดเริ่ม New Chat ใหม่
2. เลือก **Add content** และ
   - หากไม่พบไฟล์ในรายการให้เลือก **Attach** แล้ว Upload ไฟล์ <a href="/ms-agent-a-thon-2026/files/busy-workday-project-update.docx" download="busy-workday-project-update.docx">busy-workday-project-update.docx</a> และ <a href="/ms-agent-a-thon-2026/files/busy-workday-status.xlsx" download="busy-workday-status.xlsx">busy-workday-status.xlsx</a> จากในรายการ
3. Copy Prompt ด้านล่างไปวาง

```text
จากไฟล์ที่แนบ ช่วยค้นหาและสรุปเพียง 3 เรื่อง:

1. ความคืบหน้าล่าสุด
2. ปัญหาหรือความเสี่ยงที่ควรรู้
3. สิ่งที่ควรทำต่อไป

ตอบแต่ละเรื่องสั้น ๆ และระบุชื่อไฟล์ที่ใช้เป็นแหล่งข้อมูล
หากไม่พบข้อมูลในไฟล์ ให้บอกว่าไม่พบและอย่าคาดเดา
```

4. อ่านคำตอบและเปิดไฟล์ต้นทางเพื่อตรวจสอบข้อมูลสำคัญ

#### Checkpoint

- คำตอบมีไม่เกินสามรายการ
- ระบุความคืบหน้า ความเสี่ยง และงานถัดไปได้
- มีชื่อไฟล์หรือ Reference ที่ช่วยให้ย้อนกลับไปตรวจสอบได้

#### Expected Output

สรุปสั้นที่ช่วยเตรียมประชุม พร้อมแหล่งข้อมูลสำหรับตรวจสอบ
